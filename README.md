# Serenity privacy policy

The published privacy policy for the **Serenity** Android app
(`com.rajpar29.serenity`), a parental control app that blocks keywords and apps
on a single device.

Live page: https://rajpar29.github.io/serenity-privacy/

Serenity collects no personal data. Screen text read through Android's
AccessibilityService is matched against locally stored rules and discarded
immediately; the app holds no `INTERNET` permission and cannot transmit anything.

This repository contains only the policy page. The app source is kept separately.
