2. What Serenity is

Serenity is a parental control and digital wellbeing tool. It lets you define keywords and apps to block on one Android device, protects those rules with a PIN, and uses Android's accessibility service to detect blocked content and close it with the system Back action.

Serenity is not a security product, an antivirus, a network filter, a monitoring or surveillance service, or a substitute for adult supervision. It does not report to anyone, it keeps no logs, and it has no remote or web dashboard. It cannot see or control any device other than the one it is installed on.
